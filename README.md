## Overview

Using gene expression data from candidate zinc finger treatments for Angelman Syndrome, I investigated which biological systems the treatments disrupt as off-target effects. I built a weighted gene co-expression network (WGCNA) from 269 GTEx frontal cortex samples (10,000 genes), then tested whether 392 treatment-discriminating genes, identified by nearest shrunken centroids, clustered in specific modules using Fisher's exact tests with Benjamini–Hochberg FDR correction. Two modules were significantly enriched (black: 4.96-fold, FDR = 9.6×10⁻⁹; blue: 2.51-fold, FDR = 2.1×10⁻⁷). I then built a STRING protein–protein interaction (PPI) network and ranked genes by degree and betweenness centrality. Combining the two networks, I identified **7 high-risk genes** (*EP300, EZH2, ATM, KMT2C, FANCD2, AGO3, NCAPH*) that were both PPI hubs and members of an enriched co-expression module. They point to disruption of chromatin regulation and DNA damage repair.
